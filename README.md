# 💜 MisMatch

> *"Where differences spark connections."*

MisMatch is a dating app that flips the script. Instead of matching based on perfect compatibility, it celebrates the beauty of contrast. Opposites attract, and MisMatch helps people discover unexpected connections they'd never find on their own.

## Features
- **Interest-Based Matchmaking:** Finds people with complementary, not identical, hobbies.
- **"MisMatch Score":** A fun 0–100 score showing how different yet compatible two people are.
- **Astrology Integration:** Zodiac compatibility checks.
- **"Cupid" AI Chatbot:** Your personal dating assistant.

## Tech Stack
- Next.js (Pages Router)
- Tailwind CSS
- TypeScript

## Getting Started
```bash
npm install
npm run dev
```
